杠杆阶梯 / Leverage Ladder

越往上，越少人做，越耐用
01 / PARAMETER

参数

补贴、价格、算力配额。最快见效，也最容易被抵消。

02 / PROCESS

流程

重设计工作流、审批链、交付方式。中等杠杆。

03 / INFORMATION

信息流

度量什么、公开什么、谁看得见。改变行为，不靠喊话。

04 / RULES

规则

责任归属、准入、分配。把外部性写进制度。

05 / GOALS

目标

为什么做、为谁做。目标一变，流程才会真变。

06 / PARADIGM

范式

什么算工作、什么算教育、什么算价值。最难，也最持久。

多数应对停在参数层：买工具、报课程、追模型。真正耐用的应对，动的是目标与范式。
