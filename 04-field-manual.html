三个判断

Three Judgements Before Anything Else
SEC.00 / P.01
01

智能会变成基础设施。

像电一样便宜，像网络一样无处不在。它不再是某个行业，而是所有行业的地板。

Infrastructure, not industry
02

瓶颈会从执行转移到判断、验证与信任。

生成变便宜了，验证没有。谁能判断真假、好坏、值不值得，谁就站在新的瓶颈上。

Generation is cheap. Verification is not.
03

应对不是学更多工具，而是重设分工。

重新划分人与智能的工作：机器做广度与速度，人做深度、责任与意义。

Redivide the work

工具会过时，判断不会。先把判断的坐标定下来，再谈工具。

Change Quick Reference
SEC.01 / P.02
Code变化你会看到的信号对你的含义
S-01成本坍缩一份报告、一段代码、一张图的成本下降 90%+执行不再稀缺，判断与验收开始稀缺。

S-03市场极化内容过剩、渠道扁平、中间商消失注意力与信任成为终极稀缺，差异化要有证据。
S-04认知迁移「会做」不再值钱，「知道做什么」值钱记忆贬值，提问、审美、担责升值。
S-05结构震荡初级白领岗位收缩，资深判断者溢价职业极化：顶部放大、底部服务、中间空心。
S-06意义追问意义感、心理健康、生活设计成为刚需工作与身份解绑，人何以为人变成日常问题。

信号用来观察，不用来做长期决策。长期决策要回到机制层。

杠杆阶梯

Leverage Ladder
SEC.03 / P.04

同样的力气，用在不同的层级，结果差一个数量级。买工具是参数层，改流程是流程层；改度量、改目标、改对「工作」的定义，才进入高杠杆区。多数人停在第一层，所以总在追新工具。

力度 ≠ 努力程度
01 / PARAMETER

参数

补贴、价格、算力配额。最快见效，也最容易被抵消。

02 / PROCESS

流程

重设计工作流、审批链、交付方式。

03 / INFORMATION

信息流

度量什么、公开什么、谁看得见。

04 / RULES

规则

责任归属、准入、分配。

05 / GOALS

目标

为什么做、为谁做。目标一变，流程才会真变。

06 / PARADIGM

范式

什么算工作、什么算教育、什么算价值。

低高杠杆最高

如果只能做一件事，去改度量；如果能做两件，再去改目标。度量一变，行为才会真变。

先改度量，再改目标

九十天行动

A 90-Day Protocol
SEC.04 / P.05
第 1–30 天盘点 / DELEGATE

目标：找到可以被委派的工作，而不是先买工具。

第 31–60 天验证 / VERIFY

目标：让产出可被信任，而不是看起来不错。

第 61–90 天沉淀 / COMPOUND

目标：把一次性成果变成可复用资产。

九十天后，不要问「我会了几个工具」，要问「我留下了什么资产」。
