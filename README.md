# 智能时代知识地图 · 四个方案

同一个问题：智能时代会带来哪些变化，我们如何应对？
同一套内容底稿，四种完全不同的组织方式。入口是 [index.html](index.html)。

## 四个方向

| 方案 | 文件 | 它怎么组织内容 | 最适合 |
| --- | --- | --- | --- |
| 01 剖面 | [01-section.html](01-section.html) | 变化画成地层，应对画成锚点；从上往下读信号、变化、机制、常量 | 想先看懂结构、需要打印或贴墙 |
| 02 回路 | [02-loops.html](02-loops.html) | 变化画成六条因果回路，标出增强、平衡、延迟与杠杆点 | 想做分析、找最省力的下手处 |
| 03 星图 | [03-atlas.html](03-atlas.html) | 深靛蓝星空、金色星盘与几何线、水彩云气、漂浮莲花、边缘半调网点；四层星环缓慢反向旋转，鼠标跟随带细碎光点；正文、读图笔记与应对都嵌在同一页 | 想分享、想让人一眼记住 |
| 04 手册 | [04-field-manual.html](04-field-manual.html) | 可勾选、可撕下的行动手册：判断、速查、清单、杠杆、90 天、自检 | 想直接开始做 |

## 共用的内容底稿

- **6 个变化**：成本坍缩、生产重构、市场极化、认知迁移、结构震荡、意义追问
- **5 条机制**：稀缺守恒、验证瓶颈、杰文斯悖论、中间层坍缩、信任复利
- **5 个常量**：意义、时间、协调、权力、注意力
- **11 个应对**：个人 4、组织 4、社会 3

总纲：当智能变成廉价的基础设施，稀缺就从「执行」转移到「判断、信任与意义」。

## 打开方式

直接双击 `index.html`，或在浏览器中打开。四个页面都是单文件 HTML，无外部依赖，离线可用。
03 星图与 02 回路在手机上支持左右滑动查看完整图。

## 可以继续做深

选定方向后，可以把选中的方案继续做成：A3/A4 打印版、手机长图、PPT、可分享的封面页，或补齐参考文献与数据。
