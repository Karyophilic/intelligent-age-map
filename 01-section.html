01

变化层

Shifts 六种正在发生的位移
S-01

成本坍缩

认知劳动的边际成本趋近于零。生成变便宜了，验证没有。

信号 / 一份报告、一段代码、一张图的成本下降 90%+
S-02

生产重构

从「人操作工具」到「人编排智能体」。一个人可以拥有一家公司的产能。

信号 / 一人公司、三人团队、Agent 工作流
S-03

市场极化

供给爆炸，注意力与信任成为终极稀缺。标准化的中间环节被抽空。

信号 / 内容过剩、渠道扁平、中间商消失
S-04

认知迁移

记忆与检索贬值，提问、判断、审美、担责升值。

信号 / 「会做」不再值钱，「知道做什么」值钱
S-05

结构震荡

职业极化：顶部放大、底部服务、中间空心。证书与资历贬值。

信号 / 初级白领岗位收缩，资深判断者溢价
S-06

意义追问

工作与身份解绑。「人何以为人」从哲学命题变成日常问题。

信号 / 意义感、心理健康、生活设计成为刚需
02

机制层

Mechanisms 五条反复出现的底层规律
M-01

稀缺守恒

稀缺不会消失，只会转移。执行便宜了，判断与信任就贵了。

M-02

验证瓶颈

生成成本下降，验证成本不变。谁能验证，谁掌握瓶颈。

M-03

杰文斯悖论

越便宜，用得越多。总需求上升，问题规模同步放大。

M-04

中间层坍缩

标准化、可度量、可复制的中间环节最先消失。

M-05

信任复利

声誉与关系需要时间积累，无法被一次性生成。

03

常量层

Constants 变化冲不走的岩层
✳

人需要意义

人无法长期只为效率工作。

✳

信任需要时间

关系、声誉、承诺，都无法加速。

✳

协调有成本

组织存在的理由，是降低协调成本。

✳

权力趋向集中

算力、数据与分发向少数节点聚拢，也激起反作用力。

✳

注意力有限

人的时间与注意力，是唯一不增长的资源。

越往下，越接近不会轻易改变的东西。应对的锚，应该打在这里。

Reading Note
读图提示

先看地表，再看变化；越过机制，最后停在常量。然后问自己：我的锚，打在哪一层？

Anchor Schedule

应对锚点

悬停任一条目，查看它作用于哪一层。

01 个人 · Individual
P1

换栈

从技能栈到判断栈：定义问题、编排智能体、验证结果、承担后果。

作用层 / 变化层
P2

建资产

作品、声誉、关系、专有经验——无法被一次性生成的东西。

作用层 / 常量层
P3

做编排者

一个人加一组智能体，就是一家公司。学会委派、设定标准、验收。

作用层 / 变化层
P4

保反脆弱

多元收入、低成本试验、持续的学习带宽。

作用层 / 常量层
02 组织 · Organization
O1

重设计流程

先问「这件事还需要人做吗」，再问「用什么工具」。

作用层 / 机制层
O2

小前台 + 强中台

把知识、数据与判断沉淀为组织资产，让一线随时调用。

作用层 / 机制层
O3

人机分工

机器负责广度与速度，人负责深度与责任。

作用层 / 变化层
O4

度量转向

从产出量转向结果、信任与长期价值。

作用层 / 常量层
03 社会 · Society
S1

教育转向

从传授知识到训练判断：项目制、提问、终身学习。

作用层 / 常量层
S2

制度补位

社会保障、再分配、AI 责任与透明度框架。

作用层 / 机制层
S3

公共基础设施

算力、数据、模型的可及性，避免能力垄断。

作用层 / 机制层
